# My Mobile App

A cross-platform mobile app built with React Native and Expo using TypeScript.

## Quick Start

1. Install dependencies:
```bash
cd my-mobile-app
npm install
```

2. Start the app:
```bash
npm start
```

3. Run on platform:
- **Android**: Press `a` in the terminal or use `npm run android`
- **iOS**: Press `i` in the terminal or use `npm run ios` (Mac only)
- **Web**: Press `w` in the terminal or use `npm run web`

4. Test on your phone:
   - Download Expo Go app from App Store or Google Play
   - Scan the QR code shown in the terminal

## Project Structure

- `App.tsx` - Main app component
- `package.json` - Dependencies and scripts
- `tsconfig.json` - TypeScript configuration

## What's included

- React Native with TypeScript support
- Expo for easy development and testing
- Status bar component
- Basic styling with StyleSheet
